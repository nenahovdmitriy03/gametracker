# Game Tracker — Запуск

## Шаг 1 — Установи Node.js
Скачай и установи с https://nodejs.org (версия LTS)

## Шаг 2 — Установи зависимости
Открой терминал в папке проекта и выполни:
```
npm install
```

## Шаг 3 — Запусти приложение
```
npm start
```

Данные сохраняются автоматически в:
`C:\Users\<твоё имя>\AppData\Roaming\game-tracker\gametracker-data.json`

---

## Импорт Steam (необязательно)

### Получить API-ключ (бесплатно, 1 минута)
1. Зайди на https://steamcommunity.com/dev/apikey
2. Войди через Steam-аккаунт
3. Введи любой домен (например `localhost`)
4. Скопируй ключ — вставишь его прямо в приложении

### Узнать свой Steam ID (64-битный)
1. Зайди на https://steamid.io
2. Вставь ссылку на свой профиль Steam
3. Скопируй «steamID64» (начинается с 7656...)

## Резервная копия
- **Экспорт** — кнопка «Резервная копия» в сайдбаре → «Экспорт»
  Сохраняет всё в JSON-файл в любое место
- **Импорт** — та же кнопка → «Импорт»
  Восстанавливает данные из JSON-файла
